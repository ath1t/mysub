Free Public Proxy Subscription Collection

A collection of publicly available proxy node subscriptions aggregated from public GitHub repositories and automatically updated every 6 hours.

The collection is periodically maintained to remove unresponsive nodes and organize available servers by country, making it easier to find nodes based on geographic location.

Getting Started

1. Install a compatible client.
    * v2rayNG — Android
    * v2rayN — Windows
    * Hiddify — Cross-platform
    * Shadowrocket — iOS
2. Import a subscription. Copy the subscription URL for your preferred country and add it to your client’s subscription settings.
3. Update the subscription. Refresh the subscription to retrieve the latest available nodes.
4. Test and connect. Run a latency test, select a responsive node, and connect.
