Free Public VPN Subscription Collection

A curated collection of publicly available VPN node subscriptions, aggregated from GitHub and automatically refreshed every 6 hours.

The collection is periodically maintained to remove unresponsive nodes and organize available servers by country, making it easier to find and use nodes based on your preferred location.

Getting Started

1. Install a compatible client. Choose a supported VPN client, such as:
    * v2rayNG (Android)
    * v2rayN (Windows)
    * Hiddify (Cross-platform)
    * Shadowrocket (iOS)
2. Add a subscription. Copy the subscription URL for your preferred country and import it into your client’s subscription settings.
3. Update the subscription. Refresh the subscription to retrieve the latest available nodes.
4. Test and connect. Run a latency test, select a responsive server, and connect.

Important Disclaimer & Security Notice

Use these subscriptions at your own risk.

* Untrusted Infrastructure: Nodes are operated by independent third parties. Operators may monitor, inspect, or log network traffic. Avoid transmitting sensitive information or accessing banking, email, and other confidential accounts through untrusted nodes.
* Availability: Public nodes may become unavailable, unstable, or stop working without notice. Try alternative nodes if a connection fails.
* Geolocation Accuracy: Country classification is determined by server IP geolocation. Nodes using CDNs, reverse proxies, or shared infrastructure may be incorrectly categorized.
