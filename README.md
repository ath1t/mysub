## 📋 Overview

This project automatically aggregates, validates, and organizes public proxy subscriptions from various open-source repositories. Dead or unresponsive nodes are periodically purged, and active servers are categorized by geographic location for effortless access.

## 🚀 Getting Started

1. **Install a compatible client:**
   * **Android:** [v2rayNG](https://github.com/2dust/v2rayNG)
   * **Windows:** [v2rayN](https://github.com/2dust/v2rayN)
   * **Cross-platform:** [Hiddify](https://github.com/Hiddify/hiddify-app)
   * **iOS:** Shadowrocket (App Store)
2. **Import the subscription:** Copy the subscription URL for your preferred region and add it to your client's subscription settings.
3. **Update & sync:** Refresh the subscription feed to fetch the latest available nodes.
4. **Test & connect:** Run a latency check, pick a responsive node, and connect.

## ⚠️ Security & Legal Disclaimer

**Use these subscriptions at your own risk.**

* **Third-Party Infrastructure:** All nodes are operated by third-party providers. Operators may monitor or log network traffic. Avoid transmitting sensitive or personal data through public nodes.
* **Node Availability:** Public nodes can become unstable, slow, or decommissioned without prior notice.
* **Geolocation Accuracy:** Country classifications are determined via IP geolocation. Nodes utilizing CDNs or reverse proxies might appear under incorrect regions.
* **Legal Compliance:** Proxy and VPN tool usage is subject to local laws and regulations. You are solely responsible for ensuring compliance within your jurisdiction.
